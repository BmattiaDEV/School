## 🚀 Compilation

You can compile each `.cpp` file with a standard C++ compiler, for example `g++`:

Follow the complete guide from [VS Code](https://code.visualstudio.com/docs/cpp/config-mingw)

You can run each `.py` file with the Python interpreter, for example python:

Follow the complete guide from [VS Code](https://code.visualstudio.com/docs/python/python-quick-start)

You can compile each `.java` file with a standard Java compiler, for example javac:

Follow the complete guide from [VS Code](https://code.visualstudio.com/docs/java/java-tutorial)

It is recommended to use the [Code Runner](https://marketplace.visualstudio.com/items?itemName=formulahendry.code-runner)
extension to quickly run files directly from VS Code.
